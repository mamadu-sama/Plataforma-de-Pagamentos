💰 FinTouch Ledger - API de Pagamentos SimplificadaEste projeto é uma implementação de um Ledger (Livro Razão) para uma plataforma de pagamentos simplificada. O foco principal foi garantir a consistência de dados, atomicidade e o tratamento correto de concorrência em transações financeiras críticas.🚀 O DesafioO objetivo foi desenvolver uma API RESTful para transferências entre usuários (comuns e lojistas). A complexidade reside em garantir que o dinheiro nunca "suma" ou "apareça" indevidamente, tratando problemas clássicos como double spending (gasto duplo) e condições de corrida.🛠️ Decisões de Arquitetura e Soluções Técnicas1. Tratamento de Concorrência e Race ConditionsPara evitar que um usuário execute duas transferências simultâneas e fique com saldo negativo, utilizei Pessimistic Locking (SELECT FOR UPDATE).Por que? Em sistemas financeiros, o bloqueio pessimista no banco de dados garante que, enquanto uma transação lê e atualiza o saldo, nenhuma outra operação consiga interferir naquele registro específico até o COMMIT.2. Atomicidade e Integridade (ACID)As transferências são encapsuladas em anotações @Transactional. Caso o serviço autorizador falhe ou ocorra um erro de rede no meio do processo, o Spring Data JPA garante o Rollback automático, mantendo o estado do Ledger íntegro.3. Precisão NuméricaUtilizei estritamente BigDecimal para manipulação de valores monetários.Evitando Erros: Tipos primitivos como double ou float sofrem de imprecisão em cálculos decimais. Com BigDecimal, garantimos que cada centavo seja contabilizado corretamente.4. Resiliência em NotificaçõesO sistema segue o requisito de que falhas no serviço de notificação não devem cancelar a transação. Implementei um tratamento de exceção específico para o serviço de notificação, onde o erro é logado mas o fluxo principal prossegue com sucesso.📦 Tecnologias UtilizadasLinguagem: Java 17Framework: Spring Boot 3.xPersistência: Spring Data JPA / HibernateBanco de Dados: PostgreSQLDocumentação: Swagger (OpenAPI 3)Containerização: Docker & Docker ComposeTestes: JUnit 5, Mockito e RestAssured⚙️ Como Rodar o ProjetoVocê só precisa ter o Docker instalado em sua máquina.Clone o repositório:git clone [https://github.com/seu-usuario/fintouch-ledger.git](https://github.com/seu-usuario/fintouch-ledger.git)
